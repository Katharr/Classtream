# 教师端快捷键设计方案

状态：待实现的产品与技术方案。2026-10-28。

## 目标与范围

让教师在授课过程中快速隐藏共享、复制上课地址、查看讨论、管理课堂和调整预览。采用“常用操作直接按键，其他操作通过命令面板搜索”的方式，减少记忆负担。快捷键与页面按钮调用同一条业务逻辑。

首期同时提供教师网页快捷键与 Windows 全局隐藏/恢复快捷键。网页快捷键只在教师页面获得焦点时生效；全局快捷键由本机教师进程接收，在网页后台、切换标签页或浏览器最小化，以及操作 PPT、IDE 时也能触发，无须先切回网页。教师服务必须运行，教师登录会话与管理页连接仍须有效；关闭页面、锁屏、睡眠不属于后台可用承诺。

## 现有能力与必须澄清的含义

- 已有快捷键：空格暂停本地画面，F / F11 全屏，S 截图，+ / - / 0 缩放，B 课堂面板，C 课堂讨论。HTTPS 语音模式还提供按住 V 发言。
- 教师端只提供隐藏/恢复共享，不提供暂停观看或暂停预览：移除教师工具栏暂停按钮、空格暂停绑定、命令面板暂停项及相关提示。不能仅隐藏按钮而保留键盘入口。学生端现有暂停观看能力保持独立。
- 缩放、全屏和屏幕选择影响当前浏览器预览，不会让全体学生同步切换屏幕或改变缩放。
- “暂时隐藏所有屏幕”通过 `/api/screen/private` 影响学生共享；恢复后继续遵循各屏幕原有的全体、私有或指定同学权限。
- 当前没有“冻结全体学生到同一帧”、统一切换学生屏幕或独立结束课堂的完整命令。不能把这些功能直接包装成快捷键。
- 默认 HTTP 模式没有麦克风功能，语音命令与快捷键入口均不显示。

## 推荐默认按键

下表单键仅在教师已登录、页面获得焦点、没有输入或活动弹窗时生效。括号中的“本地”应出现在按钮提示和快捷键说明中。

| 操作 | 默认键 | 行为与反馈 |
| --- | --- | --- |
| 打开命令面板 | `/` | 搜索中文功能名、拼音首字母及快捷键；方向键选择，Enter 执行 |
| 查看快捷键 | `?` | 展示按分类排列的快捷键列表、当前启用状态与设置入口 |
| 隐藏全部共享 | `H` | 明确设置为隐藏；重复按仍为隐藏，成功后持续显示“学生画面已隐藏” |
| 恢复共享 | `Shift+H` | 明确恢复；保留每块屏幕原权限，成功后显示恢复结果 |
| 复制上课地址 | `L` | 复制当前固定 `/class` 地址；未创建课堂时提示先创建 |
| 创建新课堂 | `N` | 打开创建对话框并聚焦课堂名称；确认后才创建 |
| 打开/收起课堂面板 | `B` | 保留现有习惯 |
| 打开/收起课堂讨论 | `C` | 保留现有习惯，显示未读数量 |
| 开始输入讨论消息 | `T` | 展开讨论并聚焦消息输入框 |
| 查看课堂成员 | `U` | 展开面板并滚动、聚焦成员区域 |
| 选择屏幕预览（本地） | `1`–`9` | 按当前屏幕列表顺序切换；编号不存在时不执行 |
| 全部屏幕预览（本地） | `G` | 切换网格预览，不修改学生权限 |
| 全屏预览（本地） | `F` | 退出全屏可用 Esc；F11 交还浏览器管理 |
| 截图（本地） | `S` | 下载当前单屏画面；网格截图未实现前禁用并说明原因 |
| 放大 / 缩小 / 还原（本地） | `+` / `-` / `0` | 保留现有行为；网格不支持时禁用 |
| 设置画面清晰度 | `Q` | 展开“更多设置”，聚焦清晰度滑块，不直接修改数值 |
| 显示/隐藏共享鼠标 | `K` | 调用现有教师设置接口；收到成功响应后更新状态 |
| 关闭当前浮层 | `Esc` | 依次处理最上层浮层、命令面板；不退出登录或停止课堂 |

选择按键时支持大小写一致匹配；`Shift+H` 与 `?` 等显式组合独立处理。当前网页 F11 行为将调整，应在升级说明中注明。

## 命令面板与发现入口

工具栏新增“快捷操作 /”按钮和“快捷键 ?”入口。面板示例：输入“共享”，出现“隐藏全部共享”“恢复共享”“共享权限”；每条显示中文名、快捷键、影响范围，以及当前不可用的原因。

除上述操作外，面板收录：修改课堂名称/教师姓名、共享权限设置、选择指定同学、上传文件、分享代码、查看连接详情、快捷键设置和退出登录。涉及姓名或权限时打开对应区域；上传文件必须由用户选择文件；退出登录仍先确认。移出同学、删除消息等依赖具体对象的操作，只在选中对象的菜单中提供，不设置全局直接执行键。

HTTPS 模式下再展示连接语音、静音/取消静音、按住 V 发言和设备选择；V 松开、窗口失焦或页面隐藏时均停止按住发言。所有命令都保留鼠标入口。

创建新课堂打开独立确认界面。已有课堂时明确提醒“当前课堂会失效，学生需要重新进入”；焦点默认放在名称输入或取消按钮，触发快捷键的同一次按键不能自动确认。

## 防误触与状态反馈

1. 输入框、文本域、可编辑区域、下拉框、按钮和 summary 获焦时，不执行页面单键快捷键。输入法组合期间不响应；不拦截系统与浏览器保留组合。
2. 弹窗开启时只处理该弹窗的键盘操作；Tab 焦点留在弹窗内，关闭后返回触发位置。登录前与学生页面不注册教师命令；后端继续独立检查管理员身份。
3. 忽略长按重复事件。网络操作执行中锁定相同命令；共享状态操作串行执行，以服务端结果为准，失败显示原因，不能先宣称成功。
4. 隐藏和恢复采用两个明确命令，避免连续按键意外重新公开屏幕。隐藏成功后教师预览仍可继续，但顶部持续显示学生画面已隐藏。
5. 普通成功提示约 2 秒；错误提示可以关闭。状态通过文字、图标和 aria-live 表达，不只依赖颜色。
6. 截图、复制等操作保持用户手势调用链；剪贴板受限时沿用现有手动复制回退。

## 自定义

“更多设置 → 快捷键”支持总开关、单项禁用、重新录制、恢复默认。显示占用冲突并拒绝重复绑定；浏览器和系统保留键使用维护的禁用列表，并提示无法覆盖。支持关闭所有单键，仍可用鼠标打开命令面板。

网页绑定按教师浏览器保存到带版本号的独立 localStorage 键，只保存命令 ID 与按键，不保存令牌或课堂数据。页面失焦时标注“网页快捷键暂不可用”。

## Windows 全局快捷键（首期必需）

仅提供两项默认建议，首次在设置中启用：`Ctrl+Alt+H` 隐藏全部共享，`Ctrl+Alt+R` 恢复共享。用户可重新绑定；注册失败必须明确显示冲突并要求换键，不静默替代。需实测输入法、PPT 与学校常用软件的占用。

在教师进程中通过 Windows 热键注册接收事件，启动时注册、停止时释放，支持单实例和明确启用状态。全局动作直接调用服务端共享业务逻辑，反馈使用本机通知或状态指示，不将教师网页切到前台，以免打断授课。

热键仅在有效教师登录会话和当前课堂存在时可用；退出登录、会话失效时立即停止接受命令。使用进程内授权状态，不新增可绕过鉴权的 HTTP 控制接口，不把管理员令牌写入配置或日志。恢复共享时依旧保留逐屏权限。

必须处理教师网页断连状态：当前系统仍要求教师管理页在线，全局热键不能代替该连接；断连时通知“教师页面离线，请先恢复连接”。

## 实现位置与验收

在 `windows-lan` 适配层增加统一命令注册表与键盘分发模块。命令包含 ID、中文名、关键词、默认键、角色/能力条件、可用性、确认要求与执行函数。页面按钮、命令面板与按键共用命令，替换旧 setupKeyboard，避免两套监听重复执行。界面与模块纳入分享包白名单，更新帮助和教师说明。

首期验收重点：

- 教师已登录可用，学生与登录页无教师快捷键；伪造管理请求仍被后端拒绝。
- 中文输入、长按、输入框、交互控件与弹窗不会误触；Esc 和焦点恢复符合预期。
- 教师页面没有暂停按钮、暂停命令及空格暂停行为；空格不改变预览状态，学生端暂停功能不受影响；预览选屏不会修改学生权限。
- 隐藏后各学生画面不可见；恢复保持指定同学权限；慢网、失败和重复操作不会造成错误成功提示。
- 新课堂取消不改变原课堂；快捷键不能跳过确认；复制地址为当前固定入口。
- HTTP 不出现语音命令；HTTPS 按住发言失焦即停止。
- 浏览器全屏、下载与剪贴板回退真实可用；自定义绑定重载后保留，冲突可解释。

全局快捷键必须在首期验收：教师网页后台、非当前标签页、浏览器最小化及正在使用 PPT 或 IDE 时均能隐藏/恢复；确认学生实际画面变化，而非仅收到按键。覆盖真实浏览器后台连接、隐藏后恢复和原权限保留；冲突注册、注销、进程重启、教师退出、教师页断连均有清楚行为。使用临时测试课堂验证，不通过真实课堂试按高影响命令。

# 课堂使用与快捷键

学生访问教师公布的 `/class` 地址，系统自动分配动物昵称；刷新、重连和切换屏幕保持昵称，同一课堂内不重名。服务重启后重新分配。

教师使用回环地址管理课堂。学生只能观看、讨论及使用获准的共享功能，局域网请求不能登录教师后台。HTTP 模式只用于可信教学局域网，不提供麦克风和系统声音传输。

教师端提供“冻结共享 / 解除冻结”：冻结后学生保留最后画面，教师预览和讨论继续运行。解除后从原连接接收最新画面，逐屏共享权限继续生效。学生的“暂停画面”只影响本地观看。

| 操作 | 默认网页按键 |
| --- | --- |
| 快捷操作面板 | `/` |
| 快捷键设置与帮助 | `?` |
| 冻结 / 解除冻结 | `H` / `Shift+H` |
| 复制上课地址 | `L` |
| 创建课堂 | `N` |
| 课堂面板 / 课堂讨论 | `B` / `C` |
| 输入讨论消息 | `T` |
| 全屏 / 截图 | `F` / `S` |
| 放大 / 缩小 / 还原 | `+` / `-` / `0` |

当前绑定以页面帮助为准，可在帮助中修改。网页单键只在页面有焦点且没有输入或活动弹窗时生效。

Windows 全局冻结默认 `Ctrl+Alt+Shift+H`，解除冻结默认 `Ctrl+Alt+Shift+R`。教师登录并连接课堂后按保存的偏好启用，在其他应用前台也可操作。需要服务、登录和管理页连接持续有效；退出登录会注销全局按键。冲突时显示错误，应选择其他组合。绑定及启用偏好保存在本机，更新源码无需复制这些配置。

课堂讨论默认展开。教师可全体禁言或单独禁言；解除全体禁言保留单独禁言，新课堂恢复默认讨论权限。

部署和故障处理见 [教师端说明](../windows-lan/教师端说明.md)，开发验证见 [维护工具](../tools/README.md)。

# 目录结构与维护约定

2026-10-28：统一源码、分离数据，并只保留一个本机日常入口。

```text
D:\classstream\
  start.cmd                       唯一日常入口：检查、清理、启动、打开教师页面
  source/                         Git 仓库
    windows-lan/                  唯一教学版适配源码、前端和内部部署脚本
      lan.py                      launch 命令统一启动生命周期
      recover-service.ps1         检测端口和回收本部署进程
      startup_lock.py             防止同时启动的竞争
    app/                          上游参考源码，教学部署使用锁定的 PyPI 包
    tests/                        临时数据和临时端口的验证

  teacher/                        本机状态，不放源码和操作脚本
```

## 日常使用

双击工作区根目录 start.cmd。它直接运行 source/windows-lan/lan.py launch，并明确指定 teacher 为本机配置和数据目录。

1. 缺少虚拟环境、数据库或首次密码未完成时进入安装设置；已有账号和配置保留。
2. 取得启动锁，防止并行启动互相清理。
3. 读取配置端口，核对监听者的进程命令、脚本位置及部署目录。
4. 本项目旧进程先收到停止请求，最多等待 8 秒；无响应的残留经重新核对进程创建时间和身份后强制结束。不会仅凭旧 PID 文件结束进程。
5. 其他程序或另一部署占用端口时显示 PID 和进程名，停止启动。无权限清理或端口未释放时也停止并显示错误。
6. 端口释放后启动服务和网络监测，在选定教学网卡发布 mDNS 名称，写入学生短网址及 IP 备用地址，打开教师页，释放启动锁。默认学生入口为 `http://live.local`，教师后台仍仅监听回环地址。

关闭启动窗口或按 Ctrl+C 停止服务，Job Object 负责结束子服务。再次双击 start.cmd 即重启。修改源码后重新启动，教师与学生刷新页面。

根目录原 stop/check/install/password.cmd、teacher 中全部 cmd 和旧 tools/run_local.cmd 已移除。源码仓库及便携包的部署辅助脚本保留供安装、维护和分发使用，不是本机日常入口。

## 唯一源码与独立配置

以前 source/windows-lan 与 teacher 各有一份普通文件，缺少自动同步机制，导致运行旧副本。现在 teacher 不再保存 Python、JS、CSS 或 PowerShell 文件。

教学版行为只改 source/windows-lan。source/app 保留上游参考；实际教学部署使用 PyPI classtream==1.0.1 配合适配层。

teacher/config.json 是本机配置，source/windows-lan/config.json 是便携安装默认配置，两者不互相同步。CLASSTREAM_HOME 或 lan.py 的 --home 指定配置、runtime、依赖环境及可选 Caddy 的目录；前端和适配脚本从唯一源码目录加载。

源码仓库根目录的 start.cmd 用于独立便携安装。本机已有课堂数据，始终使用工作区最外层 start.cmd。

## 验证与发布

- tests/verify_startup_recovery.py：真实临时进程和随机端口，验证残留强制清理、另一部署保护、重复清理及并行启动锁。
- tests/verify_deployment_layout.py：独立配置目录、从源码提供 HTTP 资源、中文/空格路径、便携兼容和分享包白名单。
- tests/verify_windows_adapter.py：适配层集成验证，使用临时课堂数据库。
- tests/verify_mdns.py：临时课堂首页入课、短网址与 IP 回退、地址变化，以及回环网络上的真实名称解析、重名检测和资源清理。

分享前运行 python source/tools/build_windows_share.py，只分发 source/dist 的干净 ZIP。旧 releases 不自动升级，不分享 teacher 或 backups。

历史中间代码、截图、过时方案和重复测试环境已清理。历史数据库、配置和证书单独保存在工作区 backups/legacy-data/，不提交或分享。当前账号、课堂、配置、证书及依赖环境保持原路径。

工作区根入口由受 Git 管理的 `tools/create_local_launcher.py` 生成；重建命令为 `python source/tools/create_local_launcher.py`。可复用的测试服务、压力测试及检查入口统一放在 `tools/`，回归断言放在 `tests/`，运行产物只写 `.artifacts/`。

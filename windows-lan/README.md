# Classtream 局域网教学包 · HTTP 直接观看版

教师完整解压后双击 `start.cmd`，首次自动进入安装流程，默认联网下载依赖；离线依赖 ZIP 单独提供。日常仍双击 `start.cmd`，关闭启动窗口即可停止，再次双击自动回收本项目旧进程并重启。学生打开 `http://live.local` 即可观看，名称不可用时使用教师提供的 IP 备用地址。系统自动分配昵称，不安装软件、证书或浏览器插件。默认 30 FPS（目标上限）。

操作说明见 `教师端说明.md`、`学生端说明.md`、`真机验收.md`。首次安装会识别各自电脑的地址，多网卡时需要选择。分享包中的 `192.0.2.1` 是占位地址，安装时自动替换，不要发给学生。

## 安装与运行

- 教师环境：Windows 10/11、Intel/AMD x64、桌面会话、现代 Chrome/Edge。学生使用现代浏览器。
- 没有配套离线包时，首次安装需联网访问 Python.org、PyPI 及其下载站，缺少运行库时还需访问微软下载站。安装器优先复用已有 Python 3.14 x64，没有时下载固定 Python 3.14.9 官方安装程序并核对 SHA-256，为当前 Windows 用户安装；在本目录 `.venv` 建立独立环境。
- `requirements-lock.txt` 固定应用依赖，安装器固定 pip 26.2.2 并核对下载哈希。不修改原版 Classtream 安装文件。安装后会验证原生库导入和 Classtream 适配；OpenCV 无法加载时自动下载微软官方 VC++ x64 运行库，验证微软数字签名后安装，可能另需一次管理员确认。
- 安装器配置防火墙时需要 Windows 管理员确认，不关闭防火墙。学校策略禁止时需网管协助。
- 全新部署按提示设置教师密码；已有数据库保留原账户和密码。首次密码未设成功会阻止启动；误点 start.cmd 时也会引导安装。日常启动不需要联网或管理员权限。
- 不安装 Windows 服务，不设置开机自启。保持启动窗口和教师管理页在线。

### 下载慢：使用离线依赖包

将 `Classtream-Dependencies-Win64-Py314.zip` 完整解压，把里面的 **offline 文件夹和 install.ps1** 放到本目录（与 `requirements-lock.txt` 同级），替换旧安装脚本，再双击 `install.cmd`。GitHub 仓库版对应 `windows-lan` 目录；轻量分享包对应 `Classtream-LAN` 目录。看到 **OFFLINE MODE** 即已验证并使用本地依赖。

配套离线包包含 `requirements-lock.txt` 中的全部应用依赖、pip、Python 3.14.9 x64 官方安装器、微软 VC++ x64 运行库及可选 HTTPS 的 Caddy 官方 ZIP。依赖通过 `--no-index --no-cache-dir --only-binary=:all:` 安装，无需编译或在线解析。文件损坏或版本不匹配会明确停止，不会悄悄联网；恢复在线安装可把 offline 文件夹改名。

仅支持 Windows 10/11 Intel/AMD x64、标准 Python 3.14。仍须连接教学局域网，设置密码和批准必要的管理员提示；微软签名信任、Windows N 版媒体组件等系统条件仍需目标机满足。不复制他人的 `.venv` 或 runtime。

## 默认 HTTP 模式

`config.json` 中 `mode` 为 `http`。一个 Python 服务监听所有本机 IPv4 的 `80` 和回环地址 `127.0.0.1:8000`。教师打开 `http://127.0.0.1:8000/?host=admin`，学生打开 `http://live.local`，原 `/class` 入口仍可用。防火墙仅向 `LocalSubnet` 来源开放学生端口及本程序的 UDP 5353，不开放教师后台端口。

HTTP 模式的教师登录与管理 HTTP/WS 请求只允许回环来源，不信任 `X-Forwarded-For`。课堂画面、消息和文件通过 HTTP 明文传输，只用于可信教学局域网。知道固定网址的人可以进入当前课堂；这不是额外的课堂口令系统。

浏览器适配使用 `getRandomValues()` 生成 UUID v4，会话启动不依赖 `randomUUID()`；复制按钮兼容没有 Clipboard API 的浏览器，最后可手动复制。HTTP 模式隐藏语音区和发言按钮，不初始化麦克风。保留原版文字聊天、文件传输和屏幕权限功能，以真机验收为准；录制和同步传输系统声音不属于本包功能。

首页和兼容入口 `/class` 每次打开读取当前课堂 token，页面和适配脚本不缓存。教师生成新课堂后，学生刷新相同网址。重新生成 token 不会阻止知道学生网址的人再次进入。

## 可选 HTTPS 模式

停机后把 `mode` 改为 `https`，保留 `https_port: 8443`，重新运行 `install.cmd`。缺少 Caddy 时安装器按需下载 2.11.7 官方 ZIP，校验 SHA-512；启动时还校验 exe SHA-256。默认分享 ZIP 不携带 Caddy 可执行文件，HTTP 不需要它。

学生入口变为 `https://教师IP:8443/class`，屏幕和语音使用 WSS，恢复原版语音入口。教师仍可用本机地址。Caddy 自动生成本地 CA；`runtime/student-setup.zip` 可用于学生或网管信任证书，导入后重启浏览器。**此模式不承诺学生零配置**；完整功能且无证书警告需学校另配域名与浏览器信任的证书。

切换模式不会删除数据或 CA。脚本创建或更新当前模式防火墙规则；旧模式规则保留，但没有对应监听就不提供服务。管理员可删除不再使用的本包规则。许可证和校验记录在 bin 目录。

## 迁移、备份与恢复

运行数据在 `runtime/data`。从旧 Classtream 迁移时先停止两套服务，且新数据库尚未创建，然后运行：

```powershell
.\.venv\Scripts\python.exe lan.py import-data --source "$env:USERPROFILE\.classtream"
```

已有目标数据库时导入器拒绝覆盖；请先备份，停机后将目标 `runtime/data` 改名保留，再导入。导入使用 SQLite 备份 API，包含已提交的 WAL，并复制 uploads；原目录保留。新电脑不要复制其他教师的 runtime 或 .venv；需要迁移个人课堂数据时再使用此功能。

停机后备份 `runtime/data`；HTTPS 另私下备份含 CA 私钥的 `runtime/caddy-data`。公开分享只用干净 ZIP，不能包含 `.venv`、runtime、数据库、上传文件或私钥。

恢复原版：停止本包，再运行原来的 `classtream`。原安装和数据目录保留，本包新数据不会回写原目录。建议网管设置 DHCP 地址保留；HTTP 模式会检测 IP 变化并更新链接，防火墙不再绑定某个旧 IP；公布新网址即可。

## 排查

`check.cmd` 检查页面、UUID 兼容脚本、WS/WSS 与管理接口限制；HTTPS 还严格检查证书链和 IP SAN。此检查不代替学生真机和全班负载验收。

| 现象 | 处理 |
| --- | --- |
| 8000 被占用 | 先停止旧 Classtream，或改 backend_port；不要结束不认识的进程。 |
| 80 被占用 | 不结束其他应用；改 http_port 并更新防火墙，名称地址会带上新端口。 |
| live.local 打不开 | 使用邀请窗口中的 IP 备用地址；检查学生系统的 mDNS 支持、校园组播过滤和网段隔离。 |
| 学生打不开 | 核对网络与 IP，检查防火墙、访客 Wi-Fi/AP 隔离；跨子网需网管调整来源范围。 |
| 地址跳到 HTTPS | 使用完整 http:// 链接；学校强制仅 HTTPS 时交网管处理。 |
| 地址栏“不安全” | 是 HTTP 未加密提示，不是证书错误页。本模式不要求绕过证书拦截。 |
| 无课堂 / 教师离线 | 教师登录并保持页面在线，创建新课堂 创建课堂后学生刷新。 |
| 姓名串用 | 教师用 127.0.0.1，学生用局域网 IP；共享电脑核对姓名。 |
| 画面卡顿 | 看 backend.log，检查共享权限；先用 10 FPS、JPEG 质量 50–70，逐步增加学生数。 |
| 旧 ready 标记 | 先 stop.cmd；确认无本包进程后才移除异常关机留下的 runtime/ready.json。 |
| 安装失败 | 看 runtime/install.log，网络恢复后重试；不清空课堂数据。VC++ 安装日志为 runtime/vc-runtime-install.log；Windows N 版如缺少媒体组件需补装系统 Media Feature Pack。 |

每个学生独立接收 JPEG 增量块，30 FPS 是变化更新上限。无变化时不重复发送图像；教师光标单独在浏览器绘制，低速客户端可以降低实际更新率。

采集优先使用 DXcam 0.3.0 / Windows DXGI，按显示器真实坐标匹配输出；不支持或运行中失败时自动回退 MSS。新增依赖 comtypes 1.4.17 与 DXcam 均由安装入口自动安装。高帧率下使用 Python 高精度计时等待，避免 Windows asyncio 小额等待实际约 15.6 毫秒的问题；已压缩的 JPEG 不再叠加 WebSocket deflate。

### 30 FPS 低延迟传输

使用现有 DXGI/MSS、OpenCV、FastAPI 与 WebSocket，无新增运行依赖。采集在每屏独立线程中执行，避免同步截图和编码占用事件循环。采集与发送上限 30 FPS；旧的更高配置值也按 30 上限运行。

图像按 128×128 像素块比较，仅编码变化块；首次连接、画质或尺寸变化发送完整块快照。每名学生独立发送、最多一批图像在途，浏览器完成解码合成后确认；未确认期间的变化会合并保留，不积压历史帧。图像合计默认约 64 Mbps 预算，不能视为实际网络吞吐保证。

浏览器复用原有缩放、截图、暂停和多屏入口，Canvas 维护桌面基底并叠加原有教学箭头。暂停时保持画面冻结，但仍更新基底和确认，恢复后立即显示最新状态。当前保留原版固定箭头样式，尚未同步所有系统光标形状。

升级后教师和学生都刷新页面，旧协议连接需刷新后进入。backend.log 每约 5 秒记录 stream_protocol、采集/编码耗时、已确认字节与批次、合并更新数和最大确认周期；确认周期不是端到端显示延迟。空闲画面的实际图像 FPS 可以为 0。

借鉴 MeshCentral 的共享图像缓存和逐观看者发送、RFB/noVNC 的变化区域和光标绘制，以及 Guacamole 的完成帧确认；适配层独立实现，没有复制第三方代码或改变登录、课堂与共享权限逻辑。课堂真实四机网络仍需验收。

## 网络地址自动跟随（HTTP）

公开 HTTP 默认监听 0.0.0.0:80，127.0.0.1:8000 仍为本机后台。运行中约每 3–6 秒检查教学网卡；当前地址失效且只有一个有效替代地址时，更新 config.json、ready.json 和 mDNS 发布。学生仍使用相同名称，已有连接断开后需等待重连或刷新；使用旧 IP 的学生需换成新 IP。

每次 start.cmd 启动前检测有效 IP；多个候选地址时在启动窗口选择教学网卡。断网或所选地址失效时撤销名称发布，保留原配置等待恢复或重启选择网卡。可选 HTTPS 仍使用 IP 和原证书流程，不启用 mDNS。

默认 `mdns_enabled: true`、`mdns_hostname: "live"`。名称仅在选定教学网卡发布，通过 python-zeroconf 0.151.5（LGPL-2.1-or-later）和 ifaddr 0.2.0 工作。名称冲突时停止发布并显示 IP；多位教师应在各自配置中使用不同名称。正常停止会发送撤销通知，强制终止后客户端缓存最多可能保留约 30 秒。发布成功只表示本机已发布，必须用学生设备验证浏览器解析和网络组播可达性。

旧部署需安装新版锁定依赖、更新防火墙，并将本机 `http_port` 改为 80，才能使用省略端口的短地址。保留旧端口时地址自动带上该端口。旧版离线依赖包与新版依赖锁不匹配，需要重新构建。

## 教师快捷操作

主画面采用极简布局，默认收起讨论和管理面板；底部浮动工具栏集中冻结、全屏、缩放、截图、讨论及更多操作，面板展开时覆盖在画面上，不挤压共享区域。顶部课堂名菜单提供创建课堂和退出登录，在线人数进入成员列表，邀请学生复制固定网址，设置按钮提供画质、鼠标、教师姓名及快捷键设置。

教师端移除暂停按钮与空格暂停，只提供冻结/恢复学生画面。底部“更多”可搜索功能，右上角“设置 → 快捷键设置与帮助”可查看、改键和启用 Windows 全局热键。网页单键只在页面获得焦点且没有输入或弹窗时生效；全局冻结/解除可在网页后台使用，需保持教师登录、管理页连接及服务运行。默认 Ctrl+Alt+Shift+H 冻结 / Ctrl+Alt+Shift+R 解除冻结，登录连接课堂后自动注册。按键与启用偏好保存在本机（不包含令牌），冲突时明确报错并完整回滚，退出登录自动注销，服务重启后重新登录连接课堂即可恢复。冻结保留原逐屏权限，学生停留在最后一帧；解除后通过原连接自动继续，无需手动重连。详细步骤见 教师端说明.md。

# 教师端部署与使用说明

## 首次安装

1. 将 Classtream-LAN-Share.zip 解压到长期保留的目录，例如 `D:\Teaching\Classtream-LAN`，不要在压缩包内运行，不要放在学生可写的共享目录。
2. 教师机连接教学局域网，准备外网或下述离线依赖包，双击 **install.cmd**。它准备 Python 与独立依赖环境、检查并按需安装微软 VC++ 运行库、识别 IP、配置防火墙并启动服务。不需要手动执行 pip、配置 Caddy 或分发证书。
3. 多网卡时选择学生能访问的教学网卡；只有一个有效地址时自动选择。Windows 请求运行库或防火墙管理员确认时允许；无管理员权限请网管协助。
4. 全新部署按提示设置管理员密码，至少 8 位并重复输入；已有数据库保持原账户密码。密码输入不回显。
5. 等待 **READY**；浏览器自动打开教师管理页。默认用户名 admin，输入刚设置的密码；迁移部署输入原密码。
6. 点击 **创建新课堂** 创建课堂，将管理面板显示的固定 `/class` 网址发给学生。

“一键安装”指一个统一入口；首次仍可能需要设密码、选网卡、确认管理员提示。首次下载失败可恢复网络后重试。学校限制安装、脚本或防火墙时需要网管协助。

下载慢或没有外网：解压配套 `Classtream-Dependencies-Win64-Py314.zip`，把 **offline 文件夹和 install.ps1** 放进上述教学包目录，替换旧脚本；如果下载的是 GitHub 仓库，则放进 `windows-lan`。再双击原来的 `install.cmd`，出现 **OFFLINE MODE** 后会从本地安装 Python 和依赖，无需访问下载站。不要只复制 ZIP，也不要多套一层目录。密码、网卡及管理员提示仍按上述步骤操作。

## 每天上课

1. 双击 **start.cmd**，每次都会重新检测本机有效 IP；旧 IP 失效且存在多个候选地址时按提示选择教学网卡。等到 READY，登录自动打开的教师页面。
2. 保持启动窗口和管理页面在线，选择要共享的屏幕并确认学生观看权限。
3. 学生打开固定网址。需要新课堂时点击 创建新课堂，已打开页面的学生刷新即可。
4. 下课双击 **stop.cmd**，或启动窗口 Ctrl+C；关闭启动窗口也会停止子服务。

仅后台进程运行还不够，教师管理页必须保持在线。锁屏、睡眠、切换桌面可能影响采集，应现场验收。共享前关闭不希望学生看到的窗口。

## 查看本机地址

- 教师本机：[管理页](http://127.0.0.1:8000/?host=admin)，仅在教师机打开。
- 学生：`http://教师当前IP:8080/class`，以启动窗口 **Student** 一行或管理面板显示的网址为准。开头为 **http://**，默认端口 **8080**。

安装和每次启动都会检测各自 IP，教师继续使用本机地址。分享包的占位 IP 不能直接访问。

## 帧率

分享包默认 30 FPS（目标上限）。如需降低带宽或设备负担，先 stop.cmd，修改 config.json 中的 fps（1–60），再 start.cmd。帧率越高，CPU、网络发送和学生解码负担越大，实际帧率取决于设备和班级规模。

新版优先使用 GPU 桌面复制采集，兼容失败自动回退 MSS。发布测试本机在 60 设置下约 52 FPS，预热后约 56 FPS；学生端仍需真机验收。有线网卡也要检查实际协商速率：每个学生独立接收 JPEG，测试画面高帧率每路约需 65 Mbps，百兆网络无法同时承载多台这样的画面。

## 密码与检查

- 修改密码：先 stop.cmd，双击 **password.cmd**，输入用户名与两次新密码；重新启动并登录。原版没有可用的网页改密入口，请用此脚本。
- 迁移账户如仍使用原版默认密码，请正式上课前改密。不要把教师密码发给学生。
- **check.cmd** 检查服务；真实学生端和全班负载仍需按真机验收.md 测试。

## 学生与功能

学生只需打开网址、首次输入姓名。无需下载 ZIP、运行脚本、导证书或设置浏览器。地址栏“不安全”是 HTTP 未加密标记，不应出现证书错误页。

本模式提供屏幕观看、文字聊天，不提供麦克风发言，不录制或同步传输教师系统声音。需要语音时见 README 的可选 HTTPS 模式，学生流程会相应变化。

## 维护与分享

建议网管固定教师 IP（DHCP 地址保留）。HTTP 模式运行中约每 3–6 秒检测有效网卡，IP 改变后自动更新地址，公布新网址即可；教师页无须因 IP 变化重新登录。不要把生成的 .venv 复制到另一台电脑使用。

给同事只发干净的 Classtream-LAN-Share.zip。自己的数据在 runtime/data，停机后另行备份。不能把数据库、上传文件或 HTTPS 私钥混入公开分享包。

默认仅向本地子网开放。跨网段、访客 Wi-Fi 或 AP 隔离需网管调整，不需要关闭防火墙。HTTP 未加密，只用于可信教学局域网。

更新说明：本版变化更新上限 30 FPS；静态桌面不会重复发送整图，光标由浏览器叠加。升级后教师与学生都刷新页面。

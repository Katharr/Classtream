Classtream 局域网教学包 · 学生直接观看版

教师首次：解压后双击 install.cmd。
首次需联网，无 Python 时自动安装；缺少 VC++ 运行库时自动补装。
多网卡需选择，运行库或防火墙可能需确认管理员提示。
全新部署设置教师密码；已有数据库保留原密码。

教师每天：双击 start.cmd，每次自动检测本机 IP；必要时提示选择教学网卡。
登录自动打开的教师页，保持页面和启动窗口在线。
点击 New Link 创建课堂，把管理面板中的固定网址发给学生。
下课双击 stop.cmd；check.cmd 检查；停机后 password.cmd 改密。

学生：打开 http://教师IP:8080/class，输入姓名观看。
不安装软件、证书或插件，不修改浏览器设置。使用 http://，不要写成 https://。
HTTP 不加密，仅用于可信教学局域网；本模式不提供麦克风发言。

学生网址：以本机启动窗口 Student 一行或管理面板显示为准。
教师本机网址：http://127.0.0.1:8000/?host=admin
同事安装后，以自己启动窗口和管理面板中的学生网址为准。

详见 教师端说明.md、学生端说明.md、真机验收.md。
给同事只分享干净 ZIP，不分享 runtime 或 .venv。

Classtream 局域网教学包 · 学生直接观看版

教师首次：完整解压后双击 start.cmd，自动进入安装流程。
主程序包不含依赖，默认联网下载；没有 Python 时自动下载安装，缺少 VC++ 时按需补装。
无法联网时，另行解压同一 Release 的离线依赖 ZIP，把 offline 文件夹和 install.ps1
放入本目录，替换同名脚本，再运行 start.cmd；看到 OFFLINE MODE 即使用本地依赖。
多网卡时选择教学网卡；运行库或防火墙可能需要管理员确认。
全新部署设置教师密码（用户名 admin）；已有数据库保留原密码。

教师每天：双击 start.cmd，启动时自动检测本机 IP。
登录自动打开的教师页，保持页面和启动窗口在线。
点击顶部课堂名，在菜单里创建新课堂；右上角“邀请学生”复制固定网址。
主画面默认铺开，讨论、成员和设置按需展开；放大、缩小、适应窗口分别排列。
下课关闭启动窗口或按 Ctrl+C；再次双击 start.cmd 会回收本项目旧进程并重启。
维护时可用 check.cmd 检查；停机后 password.cmd 改密。

学生：打开 http://live.local，名称打不开时使用教师提供的 IP 备用地址，系统自动分配昵称。
不安装软件、证书或插件，不修改浏览器设置。使用 http://，不要写成 https://。
HTTP 不加密，仅用于可信教学局域网；本模式不提供系统声音或麦克风发言。

学生网址以启动窗口 Student 一行或“邀请学生”显示为准。
教师本机网址：http://127.0.0.1:8000/?host=admin
详见 教师端说明.md、学生端说明.md、真机验收.md。
给同事只分享干净 ZIP，不分享 runtime、.venv 或本机账户数据。

# 学生观看说明

**不需要安装任何东西。**无需下载软件、导入证书、运行脚本或修改浏览器设置。

1. 连接教师指定的教学网络。
2. 用 Chrome、Edge 等现代浏览器打开老师当堂提供的完整网址，格式为：

   **http://live.local**

   名称打不开时，使用老师提供的 IP 备用地址。不同教师可能使用不同名称。

3. 打开后即可观看，系统自动分配“小浣熊”“小熊猫”等可爱动物昵称，无需输入姓名，也不能自行改名。昵称会显示在页面顶部、课堂成员和讨论消息中。

请收藏此网址。老师开启新课堂后，刷新同一个页面即可。不要使用上一版 `https://…:8443` 链接。

共享画面默认铺开，点击底部 **讨论** 展开讨论区，未读消息会显示计数。点击顶部在线人数查看课堂成员，点击设置按钮查看连接详情和快捷键。展开面板不会缩小共享画面，可按 Esc 或关闭按钮收起。老师可全体禁言或单独禁言；禁言时讨论区会显示提示，仍可观看屏幕和阅读消息，解除禁言后即可继续发送。

底部 **放大、缩小、适应窗口** 三个按钮并列显示。点击“放大”后，可在画面上按住鼠标左键拖动，查看放大后的不同区域。点击“适应窗口”或按 `0` 还原大小并居中。此操作只影响自己的观看画面。

## 遇到问题

- **教师离线 / Host Disconnected：**等老师打开管理页，再刷新。
- **课堂尚未开始：**等老师创建课堂，再刷新。
- **课堂已更新：**刷新当前网址。
- **网页打不开：**检查教学网络，尝试老师提供的 IP 备用地址，告诉老师。
- **证书错误页：**核对开头为 http://，不是 https://。本模式不要求装证书或绕过证书警告；学校强制 HTTPS 时请老师联系网管。
- **地址栏“不安全”：**是 HTTP 未加密提示，不是证书错误。仅用老师当堂提供的网址，不在本页输入个人账户密码。

本模式没有麦克风发言，不会请求麦克风或屏幕录制权限。同一课堂中刷新、重连和切换屏幕保持昵称；服务重启后重新分配。超过 20 人时昵称添加数字后缀，避免重名。不同老师的 IP 可能不同，以当堂公布的网址为准。
